# 🧩 Design Patterns: Rust & Python 🦀🐍

A personal laboratory for exploring and implementing classic software design patterns. This repository tracks my journey in mastering architectural solutions across two different paradigms: the memory-safe, strictly-typed **Rust** and the dynamic, elegant **Python**.

> **Objective:** To understand the core intent of each pattern and how its implementation evolves when moving from high-level dynamic scripts to systems-level programming.

---

## 🛠 Repository Structure

Today the project is organized by language:

```text
.
├── python/                 # Python 3.10+ Implementations
└── rust/                   # Rust Implementations
```

The project is **planning** to organized by language and pattern category (GoF classification):

```text
.
├── python/                 # Python 3.10+ Implementations
│   ├── creational/         # Singleton, Factory, Builder...
│   ├── structural/         # Adapter, Bridge, Proxy...
│   └── behavioral/         # Strategy, Observer, State...
└── rust/                   # Rust Implementations
    ├── creational/
    ├── structural/
    └── behavioral/
```
